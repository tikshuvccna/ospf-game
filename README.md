# OSPF City · עיר הנתבים

משחק למידה בסגנון GTA2 ממבט על, שמלמד **OSPF** (בהיקף CCNA ויותר) דרך שיעורים מונפשים, סימולציות, שאלות הבנה וחידונים, ומשחקון בשלוש רמות בכל פרק.

- **8 פרקי בסיס** – ניתוב סטטי/דינמי, Link-State, Hello ושכנות, Cost, Wildcard והגדרות, DR/BDR, פקודות show, ובוס סיכום.
- **5 פרקי EXTRA** – שלבי שכנות והודעות, סוגי LSA, Dijkstra, Stub/NSSA, אימות ו-Virtual-Link.
- עולם פתוח: הליכה, נהיגה, מטבעות, חנות, דמויות.

להרצה מקומית: פשוט לפתוח את `index.html` (או `npx http-server`). אין צורך בבנייה.
